# SIH 26036 Backend

FastAPI backend for instrument verification and certificate generation system.  
Supports role-based access for **Admin**, **Inspector**, and **Owner**.

---

## 🚀 Features
- JWT authentication with role-based access
- Instrument creation and verification workflow
- Certificate generation and public verification
- Swagger UI for interactive API testing
